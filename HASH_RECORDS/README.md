# HASH RECORDS — AEGIS Governance Systems

This directory contains the cryptographic integrity infrastructure for the canonical scientific releases associated with the AEGIS / SAYTCO research ecosystem.

---

## Integrity Architecture

The hash manifests included in this directory provide:

- SHA256 verification
- Canonical release integrity validation
- DOI-linked archival consistency
- Tamper-evidence verification
- Long-term research preservation support

---

## Included Verification Layers

- Canonical PDF verification
- DOI archive integrity
- Metadata integrity
- Dependency matrix validation
- Full-package release verification

---

## Verification Standard

Algorithm:
SHA256

---

## Canonical Release Scope

The integrity manifests correspond exclusively to:

- Final canonical scientific books
- Final canonical scientific papers
- DOI-linked open scientific releases

They do not include:

- Draft versions
- Commercial publishing editions
- Under-review journal revisions
- Working development files
