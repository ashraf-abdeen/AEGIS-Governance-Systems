# حزمة سجلات الهاش النهائية المعتمدة

هذه الحزمة مولّدة مباشرة من حزمة Zenodo النهائية المعتمدة:

`ZENODO_FINAL_SOURCE_MATCHED_READY_FOR_CERTIFICATION.zip`

الغرض منها إثبات سلامة الملفات بعد التعديلات النهائية، وتوفير سجلات SHA-256 يمكن حفظها محليًا أو رفعها كملف داعم عند الحاجة.

## المحتويات

1. `ZENODO_FINAL_ARCHIVE_SHA256.txt`
   - هاش الحزمة النهائية كاملة.

2. `ZENODO_FINAL_FULL_PACKAGE_SHA256_MANIFEST.csv`
   - هاش جميع الملفات داخل الحزمة النهائية.

3. `ZENODO_FINAL_18_WORKS_SHA256.csv`
   - هاش الملفات الرئيسية للـ 18 مخرجًا فقط.

4. `ZENODO_FINAL_METADATA_SHA256.csv`
   - هاش ملفات metadata الخاصة بسجلات Zenodo.

5. `VALIDATION_SUMMARY.json`
   - ملخص اعتماد الحزمة وعدد الملفات والسجلات.

## قرار الاستخدام

اعتمد هذه النسخة فقط كسجل هاش نهائي مرتبط بحزمة Zenodo الأخيرة.
